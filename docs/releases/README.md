# Historical release notes (v0.1.0 to v0.4.0)

The files in this directory are the hand-written notes for LLMKube's first
releases, v0.1.0 through v0.4.0, all from November 2025. They are kept as a
record: the README's Performance section cites the v0.2.0 and v0.4.0 notes for
its historical benchmark numbers.

They are not maintained. Commands, field names and versions in them describe
the project as it was then, and many of their relative links point at files
that have since moved or no longer exist.

For every later release, see [CHANGELOG.md](../../CHANGELOG.md) and the
[GitHub releases page](https://github.com/defilantech/LLMKube/releases).
