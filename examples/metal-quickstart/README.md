# Metal Quickstart: a cluster and the agent on one Mac

This quickstart runs minikube and the LLMKube Metal agent on the same Apple
Silicon Mac, joins the Mac to that cluster, and serves a small model with
Metal. It now lives on the docs site, so there is one copy to keep current:

**[llmkube.com/docs/getting-started/metal-quickstart](https://llmkube.com/docs/getting-started/metal-quickstart)**

Its source is
[`docs/site/getting-started/metal-quickstart.md`](../../docs/site/getting-started/metal-quickstart.md)
in this repository; the Metal agent's release archive carries it at the same
path. For a cluster on another machine, see the
[macOS Metal Agent guide](https://llmkube.com/docs/guides/macos-metal).
